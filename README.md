# Бнихоп-Снайпер

Браузерная 3D-игра на Three.js: аркадный шутер с психоделическими эффектами, bhop-парком и бесконечным свободным миром.

## Режимы

- **Радужный лес** — отстреливай видения и следи за фокусом.
- **Bhop-парк** — проходи процедурную трассу из платформ.
- **Свободный мир** — бесконечный мир для прыжков со скоростью до 120 UPS.

## Управление

- `WASD` — движение, мышь — обзор.
- `Space` — прыжок; `A`/`D` в воздухе — стрейф.
- `ЛКМ` — атака, `ПКМ` — прицел снайперки.
- `1` — снайперка, `2` — дигл, `3` — выбранный нож; колесо мыши — смена оружия.
- `F` — осмотр оружия, `E` — взаимодействие с объектом ясности, `Esc` — меню.
- На телефоне используй экранный джойстик, свайп для обзора и кнопки.

## Запуск локально

Требуется Node.js 20.19+ или 22.12+.

```sh
npm install
npm run dev
```

Сборка и локальный просмотр:

```sh
npm run build
npm run preview
```

## Структура

- `index.html` — каркас страницы и игровые элементы интерфейса.
- `style.css` — оформление интерфейса.
- `game.js` — игровой цикл и логика Three.js.
- `vite.config.js` — конфигурация Vite и базовый путь для GitHub Pages.

Настройки баланса собраны в объекте `CONFIG` в начале `game.js`.

## GitHub Pages

Workflow `.github/workflows/pages.yml` собирает проект и публикует `dist` при push в `main`. В настройках репозитория открой **Settings → Pages** и выбери **GitHub Actions** в качестве источника публикации. После успешного workflow игра будет доступна по адресу `https://ceojellyworms.github.io/lsd/`.
